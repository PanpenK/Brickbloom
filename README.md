# Brickbloom

An ad-free, cute sliding brick puzzle. Swipe a brick and it slides until it stops; send each one out through the gate of its color before the timer runs out. Ice, one-way and lock-and-key bricks, 51 styles.

**Play:** https://panpenk.github.io/brickbloom/

- **iPhone:** open the link in Safari, tap Share, then Add to Home Screen.
- **Android:** open it in Chrome, tap the menu, then Install app.
